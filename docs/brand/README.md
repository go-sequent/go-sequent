## Meaning

The mark suggests an **event / ledger chain**: sequential links (CQRS + Event Sourcing append-only stream) with a clean finance-facing silhouette. It is conceptual branding for go-sequent — not affiliated with Ruby Sequent beyond inspiration.

## Colors

Primary palette: **navy** + **teal** (trust / ledger clarity). Prefer these assets as-is in docs; do not recolor casually.

## Usage

- README / guide titles: horizontal logo  
- Compact headers / getting-started: square mark (optional, small)  
- Keep clear space around the mark; don’t place on busy patterned backgrounds
